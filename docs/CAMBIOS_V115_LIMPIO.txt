CAMBIOS V115 LIMPIO
===================

Objetivo
--------
Evitar definitivamente la acumulacion de carpetas runtime al usar varias veces
el instalador para instalar, actualizar o hacer mantenimiento.

Cambios realizados
------------------
1. El lanzador deja de crear carpetas con PID y fecha:
   .foroactivo_installer_runtime_1234_...

2. Ahora usa una sola carpeta fija:
   .foroactivo_installer_runtime

3. Antes de abrir el instalador, intenta cerrar procesos que esten usando esa
   carpeta y despues la borra.

4. Si Windows no permite borrar la carpeta porque algun proceso externo sigue
   bloqueandola, el instalador muestra un error claro y no crea una segunda
   runtime.

Resultado esperado
------------------
Puede existir una carpeta runtime mientras el instalador esta abierto. Al cerrar,
debe desaparecer. Si no desaparece por un bloqueo de Windows, no se acumularan
mas carpetas con nombres distintos.
